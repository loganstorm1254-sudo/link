# Beacon Console

Remote console for `smmod` with **Start / Stop** buttons.

## Vercel
1. Redeploy this repo after each push
2. Env: `SESSION_SECRET`, `CONSOLE_USERNAME`, `CONSOLE_PASSWORD`

## Bridge
[BeaconConsoleBridge-Windows.zip](./BeaconConsoleBridge-Windows.zip)

Keep the bridge window open on the PC. Website Start/Stop talks to it.
