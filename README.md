# Beacon Console

Read-only remote console for your Discord bot (`smmod/smmod.py`).

## Deploy on Vercel
Import this repo → set `SESSION_SECRET` → Deploy.

## PC bridge
Download: [BeaconConsoleBridge-Windows.zip](./BeaconConsoleBridge-Windows.zip)

Unzip → run **BeaconConsoleBridge.exe** → enter your smmod **folder** path.
